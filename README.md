# Kaggle Competition: LLM-Detect-AI-Generated Text

This repository contains the code and resources used to participate in the Kaggle competition: **LLM-Detect-AI-Generated Text**. The goal of the competition was to build a model capable of detecting AI-generated text with high accuracy.

## Competition Overview
The competition required participants to classify text data as either human-written or AI-generated. This challenge was particularly relevant given the increasing sophistication of language models and the need for tools to distinguish between human and machine-generated content.

- **Model Score**: Achieved a competitive score of **0.825**, demonstrating strong performance among submissions.
- **Tech Stack**: Python, TensorFlow, Scikit-learn, and other essential NLP libraries.
